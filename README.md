🚗 iParking — Business Central Extension

Enterprise parking management module developed as a Microsoft Dynamics 365 Business Central extension.
The system integrates parking infrastructure management into an ERP environment: employees manage parking spaces, administrators configure rules, and the system tracks lifecycle, statuses and permissions.
The project demonstrates how real business processes are implemented inside an ERP using AL language, tables, pages, role centers and business logic.

✨ Features

- Parking space lifecycle management
- Parking categories, sizes and statuses
- Audit tracking (created & modified by user)
- Master data configuration (lookup tables)
- ERP style card & list pages
- Business logic validation rules
- Data consistency enforcement
- User workflow inside Business Central UI

🧠 Business Workflow

- Administrator configures parking parameters (categories, sizes, statuses)
- Employee creates parking space records
- System validates business rules
- Parking status changes are tracked automatically
- Users operate according to assigned roles
- All operations are stored in ERP database

🏗 Architecture

- Platform: Microsoft Dynamics 365 Business Central
- Language: AL
- Objects used:

  Tables
  
  Pages (Card & List)
  
  Page Extensions
  
  Enums
  
  Validation Triggers
  
  Permissions

🗄 Data Model

- Normalized relational structure
- Master data & transactional separation
- Lookup tables for controlled values
- Audit fields for tracking changes
- Business constraints implemented in AL triggers
